Personal-AI-OS

Ein macOS-first, Markdown-basiertes Personal Operating System mit lokalem Memory-Server, MCP-Zugriff und Kontext-Snapshots für KI-Agenten.

View on GitHub
Dieses öffentliche Repository ist ein Template. Echte persönliche Inhalte gehören in ein privates Repo oder einen lokalen verschlüsselten Ordner.

Das Problem mit KI heute

Herkömmliche KI-Chats starten immer bei null. Sie kennen deine Projekte, deine Ziele und deine Arbeitsweise nicht. Du musst jedes Mal von vorne erklären, wer du bist und was du brauchst.

Die Lösung: Dieses Personal-AI-OS zieht eine versionierte Kontext-Schicht ein. Je nach KI nutzt du direkten Projektzugriff, den lokalen Memory-Server/MCP oder regelmäßig aktualisierte Knowledge-Snapshots.

Memory-Infrastruktur

Der macOS-Server indiziert deine Markdown-Dateien lokal, stellt Suche und Kontext über HTTP auf 127.0.0.1:47777 bereit und bietet MCP-Tools für Live-Zugriff in kompatiblen Agenten.

Für Tools ohne Live-Schnittstelle erzeugt er aktuelle Snapshots für ChatGPT, Claude, Gemini oder Grok.

Kernfunktionen

🧠 Memory-Schichten

Trennung zwischen flüchtigem Active Memory (Tasks) und konsolidiertem Langzeitgedächtnis (Memory.md), inspiriert von OpenClaw.

⚙️ Local Memory Server

macOS-Daemon mit Datei-Watcher, lokalem Index, HTTP-API, MCP-stdio und defensivem Git-Sync für private Repositories.

🔍 Knowledge Distiller

Verwandelt statische PDFs aus dem Read-Only Documents-Ordner in strukturierte, vernetzte Wissensgraphen.

🛡️ Triage & Provenance

Schützt vor Vault Bloat durch strukturierte Filter. Jede Erkenntnis erhält Source-ID, Locator, Beleg, Konfidenz und Ableitungsart.

🔄 Lern-Loop

Wenn die KI korrigiert wird, kann sie die Korrektur in LEARNINGS.md speichern und Wiederholungsfehler reduzieren.

Die Architektur (PARA + Documents)

  • 00_Inbox: Der temporäre Sammelpunkt für schnelle Notizen und Web-Clippings.
  • 01_Projects: Aktive Initiativen mit einem klaren Ziel und einer Deadline.
  • 02_Areas: Laufende Verantwortungsbereiche ohne Enddatum (z.B. Gesundheit, Finanzen).
  • 03_Resources: Dein Wissensspeicher für destillierte Graphen, Artikel und Referenzmaterialien.
  • 04_Archive: Abgeschlossene Projekte und inaktive Notizen.
  • 05_System: Das "Gehirn" des OS (Werte, Ziele, KI-Installationsanleitungen).
  • 06_Documents: READ-ONLY. Manuell eingepflegtes Spezialwissen (PDFs, Bücher).

Inspiriert von Tiago Forte (Building a Second Brain), Andrej Karpathy, dem Obsilo-Framework und OpenClaw.
