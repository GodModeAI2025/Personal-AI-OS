# 06_Documents (Spezialwissen)

Dieser Ordner ist für **manuell eingepflegtes Spezialwissen** reserviert. 

Hier legst du Dokumente ab, die als unveränderliche Quellen (Read-Only) für die KI dienen sollen. Das können sein:
- PDFs von Büchern oder Studien
- Unternehmensrichtlinien
- Handbücher
- Umfangreiche Datensätze

## Regeln für diesen Ordner:
1. **Read-Only für die KI**: Die KI darf Dateien in diesem Ordner lesen, aber **niemals verändern oder löschen**.
2. **Keine flüchtigen Notizen**: Für schnelle Web-Clippings oder temporäre Notizen nutze `00_Inbox`.
3. **Wissens-Destillation**: Wenn du das Wissen aus einem Dokument hier extrahieren möchtest, nutze den Workflow `Knowledge_Distiller.md`. Die KI erstellt dann strukturierte Wissensgraphen in `03_Resources`, während das Originaldokument hier unangetastet bleibt.
