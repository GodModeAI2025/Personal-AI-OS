# Projects

Hier liegen alle aktiven Projekte. Ein Projekt hat immer ein klares Ziel und eine Deadline. Wenn ein Projekt abgeschlossen ist, wird es nach `04_Archive/` verschoben.

**Neues Projekt anlegen:**
1. Erstelle einen Unterordner mit dem Projektnamen (z.B. `Website_Relaunch/`).
2. Kopiere die Vorlage aus `05_System/Templates/Project_Template.md` hinein.
3. Fülle die Vorlage aus.

**Oder bitte die KI:** *"Lege ein neues Projekt an für [Thema]"*.
