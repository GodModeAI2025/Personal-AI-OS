# Archive

Hier landen abgeschlossene Projekte und inaktive Notizen. Nichts wird gelöscht. Alles bleibt durchsuchbar und kann bei Bedarf reaktiviert werden.

Wenn ein Projekt in `01_Projects/` abgeschlossen ist, verschiebe den gesamten Ordner hierher. Die KI kann bei der Weekly Synthesis vorschlagen, welche Projekte archiviert werden sollten.
