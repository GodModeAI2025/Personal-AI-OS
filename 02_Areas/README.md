# Areas (Verantwortungsbereiche)

Hier liegen laufende Verantwortungsbereiche, die kein Enddatum haben. Das sind Themen, die du dauerhaft pflegst und weiterentwickelst.

**Beispiele:** Gesundheit, Finanzen, Marketing, Team-Management, persönliche Entwicklung.

Erstelle für jeden Bereich einen Unterordner oder eine einzelne Markdown-Datei, je nach Umfang.
