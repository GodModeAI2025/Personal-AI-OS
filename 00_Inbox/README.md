# Inbox

Hier landen alle neuen Informationen, die noch nicht einsortiert sind. Das können schnelle Notizen, Web-Clippings, heruntergeladene PDFs, KI-Outputs oder eigene Gedanken sein.

Die Inbox ist ein temporärer Ort. Ziel ist es, sie mindestens einmal pro Woche zu leeren (siehe Workflow `Inbox_Processor.md`). Halte die Anzahl der Dateien hier unter 20.

**So nutzt du die Inbox:**
- Ziehe neue Dateien (PDFs, Bilder, Texte) einfach hierher.
- Bitte die KI: *"Speichere das in meiner Inbox"*.
- Nutze den Workflow *"Process Inbox"*, um alles zu sortieren.
