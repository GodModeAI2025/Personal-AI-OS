# Entscheidungs-Log (Decision Log)

*Diese Datei dokumentiert wichtige Entscheidungen, damit du (und die KI) später nachvollziehen kannst, WARUM etwas entschieden wurde. Das spart Schleifen und verhindert, dass dieselben Diskussionen immer wieder geführt werden.*

## Format

Jede Entscheidung wird wie folgt dokumentiert:

---

### [Datum] - [Titel der Entscheidung]
**Kontext:** Was war die Ausgangssituation?
**Optionen:** Welche Alternativen gab es?
**Entscheidung:** Was wurde entschieden?
**Begründung:** Warum genau diese Option?
**Auswirkungen:** Was ändert sich dadurch?

---

*Tipp: Wenn du mit einer KI eine wichtige Entscheidung triffst, bitte sie: "Dokumentiere diese Entscheidung in meinem Decision Log."*
